# TypeScript tool template

This directory is a runnable echo tool. Its contract is generated by
`scripts/vendor-contracts --service _template` in the repo. Copy this directory
outside the repo to verify portability.

```bash
npm ci
npm run build
LLM_MODE=mock npm test
docker build -t rex-tool-template .
docker run --rm -p 8080:8080 rex-tool-template
```

`AGENTS.md.tmpl` is the source for individual tool instructions. Change that
template and run `scripts/gen-docs` in the repo to update generated copies.
